Choose a lasting ID

A permit number or feature ID can identify the same record across two exports. Row numbers and recycled IDs can give misleading results. Missing or duplicate keys stop comparison.

What counts as a change?

CSV values are compared as text, including spaces and leading zeros. GeoJSON property types are preserved. Changed coordinates or coordinate order count as geometry edits. Object key order and record order are ignored. Feature IDs and geometry appear separately from properties.

Keep a history on Linux

The SQLite companion can collect a file or HTTPS feed on a schedule and export comparisons with the same matching rules. The browser keeps no uploaded data after the tab closes.
